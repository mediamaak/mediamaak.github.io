## 메이저 출판사 소개 페이지의 공통 패턴

1. 미션을 먼저 제시한다.

출판사는 단순히 책을 만든다는 설명보다, 왜 출판하는지와 누구에게 어떤 가치를 전달하는지를 먼저 말한다.

2. 출판 범위를 넓게 보여준다.

문학, 인문, 논픽션, 아동, 교육, 오디오북, 전자책, 디지털 포맷 등 출판 범위와 포맷을 구분해서 소개한다.

3. 역사와 신뢰 요소를 사용한다.

대형 출판사는 창립 연도, 임프린트, 수상 작가, 출간 규모를 사용한다. 미디어막은 아직 실제 이력이 적으므로 허위 수치 대신 `기획 중`, `준비 중`, `집필 중` 상태를 정직하게 보여주는 방식이 맞다.

4. 이미지는 장식보다 정체성 설명에 사용한다.

책, 원고, 편집, 독서, 저자, 독자, 서가, 작업실처럼 출판 행위를 보여주는 이미지가 중심이다. 기술 이미지는 출판사의 보조 포맷 또는 디지털 상품 맥락에서 쓰는 편이 자연스럽다.

5. 소개 페이지는 긴 설명보다 구조가 중요하다.

히어로, 미션, 이름의 의미, 만드는 것, 출판 철학, 준비 중인 콘텐츠, 문의 또는 다음 행동으로 이어지는 흐름이 안정적이다.

## 현재 미디어막 소개 페이지에 대한 판단

현재 소개 페이지는 브랜드 철학과 인문 출판 범위를 반영했지만, 이미지 중심으로 갈 경우 다음 균형이 필요하다.

- `미디어막`이라는 이름의 철학은 첫 화면에서 유지한다.
- 인문학 서적 출판 계획은 현재보다 더 분명히 보여도 된다.
- 코드 템플릿 이미지는 브랜드 대표 이미지가 아니라 디지털 콘텐츠 예시로 배치한다.
- 데이터/기술 이미지를 너무 앞세우면 다시 개발 블로그처럼 보일 수 있다.
- 세포막 비유는 이미지로 직접 표현하기보다, 종이의 겹, 빛의 경계, 편집된 레이어 같은 은유가 더 적합하다.

## 권장 정보 구조

1. 히어로

- 제목: 미디어막
- 대표 문구: 생각과 세계 사이에 놓인 막
- 보조 문구: 정보를 선택하고, 생각을 다듬어, 하나의 콘텐츠 세계로 만듭니다.
- 이미지: 책, 원고, 반투명 종이, 빛의 경계가 있는 대표 이미지

2. 브랜드 철학

- 막은 차단이 아니라 선택적 경계라는 점을 강조한다.
- `경계를 세우되 단절하지 않는다`를 핵심 문장으로 유지한다.
- 출판, 편집, 해석, 연결로 바로 이어지게 설명한다.

3. 출판 범위

- 인문
- 기술
- 데이터
- 경제
- 디지털 콘텐츠
- 연구 노트

인문을 첫 번째 또는 두 번째로 배치해 데이터 분석 브랜드처럼 보이는 문제를 줄인다.

4. 이미지형 콘텐츠 카드

- 인문학 서적: 책, 독서 흔적, 원고, 여백
- 출판과 편집: 책자 시안, 교정지, 편집 레이어
- 디지털 자료: 코드 템플릿, 데이터 표, 실행 설명서

5. 준비 중인 콘텐츠

실제 출간물이 없는 경우 출간 완료처럼 보이지 않게 한다.

- 인문 에세이 또는 인문 교양서: 기획 중
- 기술·데이터 실습서: 기획 중
- 디지털 코드 템플릿 패키지: 준비 중
- 연구 노트: 집필 중

구체 제목은 확정된 것만 사용한다.

6. 마무리

- 하나의 책이 하나의 세계가 될 수 있도록.
- 하나의 콘텐츠가 새로운 생각으로 이어질 수 있도록.
- 미디어막은 생각과 세계 사이에서 작동하는 경계를 만듭니다.

## 이미지 방향

### 유지할 이미지 역할

- 대표 히어로 이미지는 브랜드 철학을 설명해야 한다.
- 인문학 이미지는 미디어막이 기술·데이터만 다루지 않는다는 신호가 되어야 한다.
- 코드 템플릿 이미지는 디지털 상품 영역에서만 사용한다.

### 피해야 할 이미지

- 주식 차트, 트레이딩 화면, 암호화폐, 매매 대시보드
- 과학 교과서처럼 보이는 세포막 이미지
- 노트북 화면만 크게 보이는 개발자 포트폴리오식 이미지
- 읽을 수 있는 가짜 문자가 많은 AI 이미지
- 출간 완료 상품처럼 보이는 책 표지 목업

### 권장 이미지 톤

- 실제 출판 편집 책상 같은 장면
- 종이, 책, 원고, 교정지, 책갈피, 서가
- 디지털 자료는 코드와 데이터가 보이되, 출판 패키지처럼 정리된 이미지
- 차분한 조명과 종이 질감
- 과도한 그래픽, 3D, 애니메이션 지양

## 문구 방향

### 더 강조할 것

- 인문학 서적도 준비한다.
- 기술과 데이터는 미디어막의 일부이지 전부가 아니다.
- 출판은 정보를 쌓는 일이 아니라 선택하고 편집하는 일이다.
- 디지털 상품도 출판의 확장으로 다룬다.

### 줄일 것

- 데이터 자동화 중심 표현
- 개발 기록 중심 표현
- 자동매매 관련 최상위 표현
- 실제 판매 중처럼 보이는 표현

## 적용 우선순위

1. 소개 페이지의 정보 구조를 출판사 중심으로 재배치한다.
2. 인문 출판 범위를 첫 화면 또는 두 번째 섹션에서 더 분명히 보여준다.
3. 디지털 코드 템플릿 이미지는 보조 카드로 유지한다.
4. 준비 중인 콘텐츠 상태 표시를 추가할지 검토한다.
5. 모바일에서 이미지가 너무 길게 이어지지 않도록 이미지 수와 순서를 조정한다.

## 다음 실행안

페이지 수정 단계로 넘어갈 경우 아래 범위만 다룬다.

- `about.html`: 섹션 순서와 문구 일부 조정
- `assets/style.css`: 이미지형 카드, 모바일 간격, 섹션 균형 조정
- `assets/images/`: 필요할 경우 히어로 또는 인문 이미지 1장 교체

수정 전 확인할 사항:

- 실제 준비 중인 인문학 콘텐츠 제목을 공개해도 되는지
- 출간 예정 콘텐츠를 구체 제목으로 쓸지, 분야 단위로만 쓸지
- 현재 이미지 3장을 유지할지, 대표 이미지만 교체할지
- 소개 페이지에서 문의 CTA를 추가할지

## 2026-07-26 반영 점검

사용자 피드백: 기존 수정은 참고 사이트 검토 결과가 충분히 반영된 것처럼 보이지 않았고, 화면 차이도 크지 않았다.

이에 따라 소개 페이지는 단순 문구 보강이 아니라 메이저 출판사 소개 페이지의 공통 흐름에 맞춰 다시 재구성한다.

반영한 항목:

- 미션을 첫 화면 바로 아래에 별도 패널로 배치한다.
- 이미지 3장을 `인문 출판`, `편집의 경계`, `디지털 출판 상품`으로 역할 분리한다.
- `미디어막이 먼저 묻는 질문` 섹션을 추가해 출판사의 편집 기준을 드러낸다.
- 출판 범위에서 인문·교양을 가장 먼저 배치해 데이터 분석 중심 인상을 줄인다.
- 준비 중인 콘텐츠는 상태 배지를 유지해 실제 출간물처럼 보이지 않게 한다.
- 자동매매와 데이터 자동화 기록은 하위 연구 노트로 남긴다.

이번 반영 후에도 보완할 수 있는 항목:

- 실제 준비 중인 인문학 원고의 분야나 가칭 제목을 공개할 수 있는지 확인한다.
- 대표 히어로 이미지를 더 출판사다운 서가, 원고, 독서 장면으로 교체할지 검토한다.
- 모바일에서 이미지가 길게 이어지는 느낌이 있으면 이미지형 카드 수를 줄인다.
