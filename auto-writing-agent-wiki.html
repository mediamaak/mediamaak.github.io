ARCHITECTURE

전체 흐름

01자료 수집RSS, API, 공식 블로그, 리서치 자료에서 후보 URL과 메타데이터를 모읍니다.
02중복 제거이미 사용한 URL, 같은 제목, 낮은 신뢰도 자료를 발행 후보에서 제외합니다.
03주제 랭킹퀀트 투자 relevance, 최신성, 실무 적용성을 기준으로 하루 후보를 좁힙니다.
04Codex 작성원문 전문 번역이 아니라 핵심 요약과 투자 리서치 관점의 해석을 작성합니다.
05품질 평가출처, 과장 표현, 저작권 위험, 환각 가능성, 한국어 품질을 검사합니다.
06정적 발행승인된 글만 HTML, JSON, 사이트맵에 반영해 GitHub Pages에 공개합니다.

MODULES

Codex 구현 단위

COLLECTOR

자료 수집기

소스 설정 파일을 읽어 후보 자료의 제목, URL, 발행일, 출처, 태그를 표준 스키마로 저장합니다.

RANKER

주제 선별기

퀀트 투자, 거시경제, 위험관리, 데이터 분석 관점에서 글감 우선순위를 계산합니다.

WRITER

작성 에이전트

Codex가 원문 근거를 유지하면서 한국어 요약, 실무 적용 포인트, 출처 링크를 작성합니다.

EVALUATOR

품질 평가기

중복, 출처 누락, 장문 인용, 투자 조언성 표현, 확정적 예측을 차단합니다.

PUBLISHER

발행기

승인된 초안을 GitHub Pages용 게시글 HTML과 목록 JSON으로 변환합니다.

FEEDBACK

독자 반응 분석

조회수와 클릭률 지표가 준비되면 다음 후보 랭킹과 작성 프롬프트에 반영합니다.

QUALITY RULES

발행 기준

  • 원문 링크 없이 단독 주장하지 않습니다.
  • 원문 전문 번역, 장문 인용, 표 구조 복제를 피합니다.
  • 투자 수익 보장, 매수·매도 지시, 확정적 전망 표현을 사용하지 않습니다.
  • 최근 자료를 우선하되, 시의성이 낮은 자료는 배경 설명 또는 참고 자료로만 둡니다.
  • 품질 평가를 통과하지 못한 초안은 공개 페이지에 반영하지 않습니다.
