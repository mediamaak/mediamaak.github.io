ABOUT MEDIAMAK

미디어막이라는 이름

미디어막은 기술과 데이터를 읽기 쉬운 도서, 전자책, 실습 자료와 디지털 콘텐츠로 정리하는 출판 브랜드입니다.

NAME

Media + Mak

Media는 글, 리포트, 문서, 출판물처럼 공개 가능한 기록을 뜻합니다. Mak은 만들고 쌓아 올리는 작업을 가볍게 줄인 이름으로 사용합니다.

SCOPE

콘텐츠로 만드는 대상

기술, 데이터, 경제 분야의 실용 자료와 직접 개발하고 검증한 연구 노트를 다룹니다.

BOUNDARY

공개와 판매 원칙

  • 출간 또는 판매가 확정되지 않은 항목은 준비 상태를 명확히 표시합니다.
  • 연구 노트는 출판 콘텐츠의 근거 자료이며 투자 권유나 수익 보장을 목적으로 하지 않습니다.
  • 계정, 주문 상세, API 키, 관리자 로그처럼 민감한 정보는 공개하지 않습니다.
