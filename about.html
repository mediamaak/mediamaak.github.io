ABOUT MEDIAMAK

미디어막

생각과 세계 사이에 놓인 막

미디어막은 인문, 기술, 데이터, 경제를 가로지르는 정보와 이야기를 선택하고 편집해 하나의 콘텐츠 세계로 만드는 출판 브랜드입니다.

MISSION

세상의 모든 정보를 그대로 옮기지 않습니다.

미디어막은 필요한 것을 선택하고, 충분히 검토하고, 읽을 수 있는 순서로 다시 배열합니다. 한 권의 책, 하나의 전자책, 하나의 디지털 자료가 각자의 관점과 흐름을 갖도록 만드는 일을 출판으로 봅니다.

HUMANITIES

인문학 서적도 준비합니다

삶, 사회, 언어, 관계, 사유를 다루는 글은 미디어막의 중요한 출판 범위입니다. 사람이 세계를 이해하는 방식과 질문을 책의 언어로 다듬습니다.

EDITORIAL BOUNDARY

경계를 세우되 단절하지 않습니다

막은 세계를 가르는 벽이 아니라, 하나의 세계를 성립시키면서 다른 세계와의 관계를 조절하는 경계입니다.

DIGITAL CONTENTS

디지털 자료도 출판의 확장입니다

코드 템플릿, 데이터 표, 실행 설명서도 독자가 이해하고 다시 사용할 수 있는 디지털 출판 상품으로 정리합니다.

PUBLISHING QUESTIONS

미디어막이 먼저 묻는 질문

출판은 무엇을 남기고 어떤 순서로 전달할지 선택하는 일입니다.
01왜 지금 읽어야 하는가주제가 독자에게 필요한 이유와 오래 남을 질문을 확인합니다.
02누구에게 닿아야 하는가독자의 배경, 관심, 읽는 상황을 먼저 생각합니다.
03어떤 경계가 필요한가담을 것과 덜어낼 것을 정해 하나의 관점을 분명히 합니다.
04어떤 형식이 맞는가책, 전자책, 리포트, 코드 패키지 중 내용에 맞는 형태를 고릅니다.

NAME

이름의 의미

미디어막의 막은 세포막과 같은 경계를 떠올리게 합니다. 막은 안과 밖을 구분하고 내부를 보호하지만, 외부와 완전히 단절하는 벽은 아닙니다.

필요한 것은 받아들이고 불필요한 것은 걸러내며, 안과 밖이 서로 신호를 주고받도록 합니다. 미디어막은 이러한 선택적인 경계의 의미에서 출발했습니다.

MEDIA

미디어와 막

미디어는 생각과 사람을 연결하는 매개입니다. 막은 그 사이에서 기준을 세우고 내용을 선택하며 하나의 세계를 형성하는 경계입니다.

미디어막은 수많은 정보, 기술, 경험, 사유와 이야기를 그대로 전달하지 않습니다. 가치 있는 것을 선택하고, 이해할 수 있는 구조로 다듬고, 새로운 맥락을 더해 콘텐츠로 만듭니다.

경계를 세우되 단절하지 않습니다. 분리와 보호만이 아니라 선택, 해석, 편집, 연결, 교류를 통해 하나의 콘텐츠 세계를 형성합니다.

PUBLISHING

미디어막이 생각하는 출판

출판은 정보를 단순히 쌓아 놓는 일이 아니라, 무엇을 남기고 어떤 순서로 전달할지 선택하는 일입니다.

좋은 콘텐츠는 세상의 모든 것을 담으려 하지 않습니다. 인문학 서적이든 기술 실습서든, 명확한 경계를 갖고 그 안에서 하나의 관점과 흐름을 완성합니다.

미디어막은 사람과 세계를 이해하는 질문, 기술을 다루는 방법, 데이터를 읽는 관점을 필요한 만큼 선택하고, 충분히 검토하고, 오래 사용할 수 있는 형태로 정리합니다.

하나의 책이 하나의 세계가 될 수 있도록. 하나의 콘텐츠가 새로운 생각으로 이어질 수 있도록. 미디어막은 생각과 세계 사이에서 작동하는 경계를 만듭니다.
