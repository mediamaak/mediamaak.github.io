글 자동 작성 에이전트

자료 조사, 초안 작성, 품질 평가, 정적 페이지 반영까지 하나의 흐름으로 구성합니다.

MediaMaak의 자동 작성 글은 RSS/API/공식 블로그에서 후보 자료를 모으고, 중복 URL을 제외한 뒤 Codex로 한국어 요약 초안을 만듭니다. 이후 출처성, 최신성, 저작권 위험, 과장 표현을 점검한 글만 GitHub Pages용 HTML과 JSON 데이터로 반영합니다.

Codex에서는 수집기, 작성기, 평가기, 발행기를 각각 독립 모듈로 구현하고 테스트할 수 있습니다. 운영 단계에서는 스케줄러가 매일 실행하고, 사용자는 아래 일별 목록에서 에이전트가 작성한 글을 날짜순으로 확인합니다.

일별 자동 작성 글 보기 구현 위키 보기
  1. 01자료 수집

    RSS, API, 공식 블로그 자료를 모으고 이미 사용한 URL을 제외합니다.

  2. 02Codex 작성

    선별 자료를 바탕으로 짧고 실무적인 한국어 요약 초안을 작성합니다.

  3. 03품질 평가

    출처, 중복, 저작권, 환각 가능성, 표현 위험을 발행 전 점검합니다.

  4. 04Pages 반영

    승인된 글을 정적 HTML과 게시글 데이터로 변환해 블로그에 노출합니다.
